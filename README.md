# Sistema de Gestão de Chamados 🛠️

Este projeto é um sistema desenvolvido para gerenciamento e acompanhamento de chamados de suporte técnico, com foco em organização de rotinas operacionais, registro de ocorrências e facilidade de navegação para o usuário.

## 📌 Funcionalidades

* **Abertura de Chamados:** Registro de solicitações com descrição do problema e nível de prioridade.
* **Acompanhamento de Status:** Visualização em tempo real do andamento do atendimento.
* **Gestão de Atendimentos:** Organização e histórico de chamados finalizados e pendentes.

## 🛠️ Tecnologias Utilizadas

* **Linguagem de Programação:** Python 
* **Banco de Dados:** MySQL

## 🎯 Objetivo do Projeto

Desenvolvido para consolidar conceitos de desenvolvimento de software, estrutura de dados e automação de processos de suporte técnico.
